# افزونه‌ی وردپرس رویدادیار (Conference Day)

سرور هر چهار اپ رویدادیار: API همگام‌سازی گوشی‌ها (`/wp-json/conf/v1/device/*`)، API اپ مدیریت (`/admin/*`)، صفحه‌ی عمومی `/c/<token>` و داشبورد پیشخوان.

## نصب و به‌روزرسانی

1. از خروجی ساخت گیت‌هاب `roydadyar-wp-plugin` را دانلود و باز کنید؛ فایل `conference-day.zip` داخلش را در «افزونه‌ها ← افزودن ← بارگذاری» بدهید و «جایگزینی نسخه‌ی فعلی» را بزنید.
2. نام پوشه (`conference-day`)، مسیر API (`conf/v1`) و پیشوند جدول‌ها (`wp_cd_`) عوض نشده‌اند؛ داده‌ها و اپ‌های نصب‌شده می‌مانند.
3. جدول‌ها با اولین بارگذاری خودکار به‌روز می‌شوند (ستون‌ها و جدول‌های تازه، بدون حذف داده)؛ از هر نسخه‌ی قبلی.
4. بعد از به‌روزرسانی «رویدادیار ← راهنما» را باز کنید؛ اگر در وضعیت سیستم چیزی قرمز بود «بازنشانی پیوندها» را بزنید.
5. کلیدهای قبلی (کلید اصلی و کلیدهای گوشی) کار می‌کنند و در «اتصال اپ‌ها» دیده می‌شوند؛ چون متنشان پیش‌تر ذخیره نمی‌شد، برای دیدن و کپی دوباره یک بار «بازتولید» کنید.

## تغییرهای ۲٫۰ · فیروزه

| بخش | چه شد |
| --- | --- |
| پیشخوان | داشبورد (و «شروع» بار اول)، رویدادها (بایگانی و برگرداندن)، اتصال اپ‌ها، صفحه‌های عمومی، راهنما و وضعیت سیستم. |
| داشبورد روی صفحه‌ی وب | اختیاری، در «صفحه‌های عمومی»: آدرس دلخواه (آدرس تکراری با برگه‌ها رد می‌شود)، «فقط مدیران» یا «کلید داخل لینک»؛ فقط خواندنی، noindex، بدون کش. |
| کلیدها | یک فهرست با نقش (مالک، مدیر اجرایی، فقط گزارش)، رمزشده و همیشه قابل دیدن؛ هر مسیر API نقش لازمش را می‌سنجد. `ping` نقش کلید را برمی‌گرداند. |
| پین نیروها | رمزشده و قابل دیدن برای مدیر (`GET …/staff`)، ورود با یک کوئری، نیروی قدیمی در اولین ورود منتقل می‌شود. قفل تلاش ناموفق به‌ازای (IP، رویداد)، ۳۰ تلاش در ۱۰ دقیقه. |
| رویداد | بایگانی (فقط خواندنی، ورود نیرو بسته)، حذف کامل فقط بدون کار ثبت‌شده. |
| داده | حذف نرم افراد، ورودی‌های اکسل، حذف نوع/نقش/وعده با انتقال، وعده‌ی غیرفعال، حضور روزانه (`day`)، `meal_undo`، ادغام و ویرایش فرد، کارت باطل، وضعیت چاپ، رد کار بدون اجازه (`rejected_events`)، گزارش روزانه و خروجی با فیلتر. |

## ثبت‌نام آنلاین (DB نسخه‌ی ۸)

| بخش | چه شد |
| --- | --- |
| جدول‌ها | `wp_cd_reg_pages` (یک صفحه برای هر رویداد)، `wp_cd_registrations` (با `paid_at` و `archived_at`)، `wp_cd_reg_messages` (پیام‌های فرستاده‌شده)؛ ستون‌های `extra`، `extra_meals`، `onsite_due`، `onsite_note`، `reg_code` روی شرکت‌کننده. |
| پیشخوان | «صفحه‌ی ثبت‌نام» در ۷ گام، «ثبت‌نام‌ها» با پنل جزئیات، و «اتصال درگاه و سرویس پیامک» (`?page=cd-reg-page&view=connect`). |
| پرداخت | زرین‌پال، درگاه دلخواه (`CD_Gateway_Custom` از روی تنظیم)، و هر درگاه با قلاب `roydadyar_payment_gateways`. |
| پیامک | اتصال دلخواه HTTP یا قلاب `roydadyar_sms_providers` (هر سرویس: `['name' => …, 'send' => callable($mobile, $text) → [ok, پاسخ]]`). پیام‌ها با قلاب `roydadyar_registration_status` فرستاده می‌شوند. |
| روز اجرا | رخداد تازه‌ی گوشی `onsite_settled` (نیروی پذیرش یا مدیر؛ مبلغ از سرور؛ تسویه‌ی دوباره علامت `duplicate_settle`، بدون بدهی رد `nothing_due`). گزینه‌ی وصل به وعده در سنجش حق وعده حساب می‌شود. |

## تغییرهای ۰٫۲ (پیشین)

| بخش | چه شد |
| --- | --- |
| تنظیم‌های رویداد | ستون `settings` روی رویداد: `identify_mode` (scan / card / none)، `qr_behavior` (person / redirect / vcard)، `qr_redirect_url`، `contact_fields`، `show_maker_credit`. با «ذخیره روی سرور» در پیکربندی اپ مدیریت فرستاده می‌شود، `config_version` را بالا می‌برد و در هر دو snapshot (داخل `event.settings`) برمی‌گردد. |
| ثبت‌نام در محل | در رویداد «بدون کارت» `walkin_register` بدون `card_token` پذیرفته می‌شود. |
| صفحه‌ی عمومی | سیستم طراحی «فیروزه»؛ فونت وزیرمتن از خود هاست (`assets/fonts`، OFL)؛ «الان» و «بعدی» به وقت تهران؛ روزهای دیگر جمع‌شده؛ «ذخیره در مخاطبین» (`?vcf=1`) فقط با فیلدهای مجاز؛ «انتقال به آدرس» (اگر مقصد خراب باشد صفحه‌ی فرد)؛ خط سازنده‌ی قابل خاموش‌کردن؛ کش ۶۰ ثانیه‌ای LiteSpeed؛ محدودیت توکن‌های نامعتبر پشت‌سرهم از یک IP. |
| شرکت‌کننده | ستون‌های `share_contact` («خیر» = فقط نام و سازمان) و `website` (دکمه‌ی صفحه‌ی شخصی). در ورود اکسل اپ مدیریت قابل نگاشت‌اند. |
| API مدیریت | `GET …/attendees/{id}/timeline` (تاریخچه‌ی یک نفر)، `POST …/attendees/{id}/checkin-undo` (لغو پذیرش از اپ مدیریت)، `GET/POST …/card-template` (قالب کارت روی سرور؛ در snapshot مدیریت هم برمی‌گردد). |
| برند | نام افزونه «رویدادیار (RoydadYar)»، سازنده NewVisionteam، منوی «رویدادیار»، پانویس فقط در صفحه‌های خود افزونه، لینک «پشتیبانی» و جعبه‌ی «درباره». |

## آزمون

`php -l` روی همه‌ی فایل‌ها در CI اجرا می‌شود. منطق تنظیم‌ها، vCard، اعتبارسنجی ثبت‌نام در محل و صفحه‌ی عمومی با یک آزمون PHP بدون وردپرس بررسی شده؛ آزمون‌های نسخه‌ی ۲ هم روی همین بستر (با MariaDB) اجرا شده‌اند؛ نصب واقعی روی وردپرس را پیش از رویداد بیازمایید.
