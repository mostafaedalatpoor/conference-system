# افزونه‌ی وردپرس رویدادیار (Conference Day)

سرور هر چهار اپ رویدادیار: API همگام‌سازی گوشی‌ها (`/wp-json/conf/v1/device/*`)، API اپ مدیریت (`/admin/*`)، صفحه‌ی عمومی `/c/<token>` و داشبورد پیشخوان.

## نصب و به‌روزرسانی

1. از خروجی ساخت گیت‌هاب `RoydadYar-WordPress-plugin-<نسخه>` را دانلود و باز کنید؛ فایل zip داخلش (`RoydadYar-WordPress-plugin-0.3.0.<ساخت>.zip`، با پوشه‌ی `conference-day` در ریشه) را در «افزونه‌ها ← افزودن ← بارگذاری» بدهید و «جایگزینی نسخه‌ی فعلی» را بزنید.
2. نام پوشه (`conference-day`)، مسیر API (`conf/v1`) و پیشوند جدول‌ها (`wp_cd_`) عوض نشده‌اند؛ داده‌ها و اپ‌های نصب‌شده می‌مانند.
3. جدول‌ها با اولین بارگذاری خودکار به نسخه‌ی ۳ می‌روند (ستون‌های تازه، بدون حذف داده).
4. بعد از به‌روزرسانی یک بار «تنظیمات ← پیوندهای یکتا ← ذخیره» را بزنید تا مسیر `/c/` تازه شود.

## تغییرهای ۰٫۳

| بخش | چه شد |
| --- | --- |
| قالب کارت | `card-template` کلیدهای تازه را می‌پذیرد: `setup_done`، `double_sided`، `qr_enabled`، `qr_side` (front / back) و `texts` (حداکثر ۴۰ متن؛ هر متن با `side`، `source` از static / field / column / file، `value`، `prefix`، `suffix`، جا، عرض، چینش، فونت، اندازه، رنگ، `max_lines` ۱ تا ۵، `on_reserve`). کلید ناشناخته و مسیرهای محلی (`front_image`، `extra_file`) ذخیره نمی‌شوند. |
| ستون‌های اضافه | ستون `extra` (JSON) روی شرکت‌کننده: ستون‌های نگاشت‌نشده‌ی اکسل ورود، حداکثر ۵۰ ستون. فقط در snapshot مدیریت برمی‌گردد، نه snapshot گوشی نیروها. ثبت‌نام در محل آن را پاک نمی‌کند. |
| فونت‌ها | `GET/POST /admin/fonts`، `GET /admin/fonts/{id}` (فایل به base64)، `POST /admin/fonts/{id}/delete`. فقط TTF، حداکثر ۸ مگابایت و ۳۰ فونت. فایل‌ها در `wp-content/uploads/roydadyar-fonts` با `.htaccess` بسته به روی وب. |
| افراد ناقص | ورود اکسل شرکت‌کننده‌ی بدون نام یا نام خانوادگی را هم می‌پذیرد؛ فقط ردیفی که نه نام دارد نه ایمیل و موبایل رد می‌شود. در به‌روزرسانی، مقدار خالی نام، نام خانوادگی، موبایل و ایمیل چیزی را پاک نمی‌کند. |
| تکمیل اطلاعات | رخداد تازه‌ی `attendee_update` از گوشی نیروها (`payload.fields` فقط با `first_name`، `last_name`، `mobile`، `email`). روی شرکت‌کننده اعمال می‌شود، در دفتر می‌ماند تا گوشی‌های دیگر هم بگیرند، و در تاریخچه‌ی فرد با `detail` («نام خانوادگی: کریمی») برمی‌گردد. |
| نسخه | هر ساخت CI نسخه را «۰٫۳٫۰.شماره‌ی ساخت» می‌کند تا در وردپرس معلوم باشد کدام ساخت نصب است. |

## تغییرهای ۰٫۲

| بخش | چه شد |
| --- | --- |
| تنظیم‌های رویداد | ستون `settings` روی رویداد: `identify_mode` (scan / card / none)، `qr_behavior` (person / redirect / vcard)، `qr_redirect_url`، `contact_fields`، `show_maker_credit`. با «ذخیره روی سرور» در پیکربندی اپ مدیریت فرستاده می‌شود، `config_version` را بالا می‌برد و در هر دو snapshot (داخل `event.settings`) برمی‌گردد. |
| ثبت‌نام در محل | در رویداد «بدون کارت» `walkin_register` بدون `card_token` پذیرفته می‌شود. |
| صفحه‌ی عمومی | زبان طراحی «دفتر»؛ فونت وزیرمتن از خود هاست (`assets/fonts`، OFL)؛ «الان» و «بعدی» به وقت تهران؛ روزهای دیگر جمع‌شده؛ «ذخیره در مخاطبین» (`?vcf=1`) فقط با فیلدهای مجاز؛ «انتقال به آدرس» (اگر مقصد خراب باشد صفحه‌ی فرد)؛ خط سازنده‌ی قابل خاموش‌کردن؛ کش ۶۰ ثانیه‌ای LiteSpeed؛ محدودیت توکن‌های نامعتبر پشت‌سرهم از یک IP. |
| شرکت‌کننده | ستون‌های `share_contact` («خیر» = فقط نام و سازمان) و `website` (دکمه‌ی صفحه‌ی شخصی). در ورود اکسل اپ مدیریت قابل نگاشت‌اند. |
| API مدیریت | `GET …/attendees/{id}/timeline` (تاریخچه‌ی یک نفر)، `POST …/attendees/{id}/checkin-undo` (لغو پذیرش از اپ مدیریت)، `GET/POST …/card-template` (قالب کارت روی سرور؛ در snapshot مدیریت هم برمی‌گردد). |
| کلید گوشی مدیر | در «رویدادیار ← تنظیمات» برای هر گوشی مدیر کلید جدا ساخته و جدا باطل می‌شود. کلید اصلی (اپ ویندوز) دست نمی‌خورد. |
| برند | نام افزونه «رویدادیار (RoydadYar)»، سازنده NewVisionteam، منوی «رویدادیار»، پانویس فقط در صفحه‌های خود افزونه، لینک «پشتیبانی» و جعبه‌ی «درباره». |

## آزمون

`php -l` روی همه‌ی فایل‌ها در CI اجرا می‌شود. منطق تنظیم‌ها، vCard، اعتبارسنجی ثبت‌نام در محل، صفحه‌ی عمومی، پاک‌سازی قالب کارت و ستون‌های اضافه، و بارگذاری و حذف فونت با یک آزمون PHP بدون وردپرس بررسی شده؛ نصب واقعی روی وردپرس هنوز آزموده نشده است.
